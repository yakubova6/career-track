# Интерактивный конструктор карьерного трека

## О проекте

**Интерактивный конструктор карьерного трека** — программная система для студентов и начинающих специалистов, которая помогает определить необходимые для выбранной профессии навыки и сформировать персональный план их развития.

Система анализирует требования реальных вакансий на рынке труда, выделяет наиболее востребованные **Hard Skills** и **Soft Skills**, сравнивает их с текущими навыками пользователя и определяет области для развития.

Главный результат работы системы — **пошаговый карьерный трек**, показывающий, какие навыки необходимо развивать и в какой последовательности.

---

## Проблема

Студенту, который хочет начать карьеру в определённой области, часто сложно самостоятельно определить:

* какие навыки действительно востребованы работодателями;
* какие требования являются обязательными, а какие желательными;
* каких навыков ему не хватает;
* в каком порядке изучать необходимые технологии;
* какие навыки имеют наибольший приоритет;
* насколько текущий уровень подготовки соответствует выбранной позиции.

Поиск информации по отдельным вакансиям, образовательным платформам и статьям не формирует единой картины развития.

---

## Цель проекта

Разработать концепцию программной системы, которая на основе анализа рынка труда формирует для студента персональный маршрут развития навыков от текущего уровня до выбранной профессиональной позиции.

---

## Целевая аудитория

Основные пользователи системы:

* студенты, планирующие первую работу;
* начинающие специалисты;
* пользователи, меняющие профессиональное направление;
* пользователи, которые хотят определить недостающие навыки для конкретной должности.

---

## Основной сценарий работы

1. Пользователь указывает желаемую профессию или должность.
2. Система получает и анализирует вакансии по выбранному направлению.
3. Из вакансий выделяются профессиональные требования и навыки.
4. Навыки классифицируются на:

   * Hard Skills;
   * Soft Skills.
5. Система определяет наиболее часто встречающиеся и значимые навыки.
6. Пользователь указывает свои текущие навыки и уровень владения ими.
7. Система сравнивает текущий профиль пользователя с требованиями выбранной позиции.
8. Формируется **Skill Gap** — список недостающих или недостаточно развитых навыков.
9. Для навыков определяется приоритет развития.
10. На основе зависимостей между навыками формируется последовательный карьерный трек.
11. Пользователь получает визуальное представление своего плана развития.

---

## Пример

Пользователь выбирает цель:

**Frontend Developer — Junior**

Система анализирует вакансии и определяет набор часто встречающихся требований:

```text
JavaScript
HTML
CSS
Git
React
TypeScript
REST API
Адаптивная вёрстка
Работа в команде
Коммуникация
```

Пользователь указывает текущие навыки:

```text
HTML        — высокий уровень
CSS         — высокий уровень
JavaScript  — средний уровень
Git         — базовый уровень
React       — средний уровень
TypeScript  — отсутствует
REST API    — базовый уровень
```

Система определяет пробелы и формирует последовательность:

```text
1. JavaScript — углубление
        ↓
2. REST API
        ↓
3. TypeScript
        ↓
4. React + TypeScript
        ↓
5. Практический проект
        ↓
6. Подготовка к собеседованию
```

Таким образом, пользователь получает не просто список технологий, а **структурированный маршрут развития**.

## Ключевые функции системы

### Анализ рынка труда

* получение данных о вакансиях;
* фильтрация вакансий по профессии, уровню и другим параметрам;
* выделение требований;
* определение востребованности навыков;
* анализ динамики требований.

### Профиль пользователя

* создание профиля;
* указание желаемой позиции;
* добавление имеющихся навыков;
* указание уровня владения навыками;
* отслеживание прогресса.

### Анализ Skill Gap

Система сравнивает:

**Текущие навыки пользователя**

с

**Требованиями выбранной профессиональной позиции.**

Результатом является список:

* освоенных навыков;
* навыков, требующих улучшения;
* отсутствующих навыков.

### Построение карьерного трека

Для каждого недостающего навыка система определяет:

* приоритет;
* необходимый уровень;
* зависимости от других навыков;
* рекомендуемый порядок изучения.

### Визуализация

Пользователь получает визуальное представление карьерного маршрута:

```text
Текущий уровень
      ↓
Базовые навыки
      ↓
Профессиональные навыки
      ↓
Продвинутые навыки
      ↓
Практика
      ↓
Целевая позиция
```

## Концепция Skill Gap

Одной из центральных сущностей системы является **Skill Gap** — разница между текущими навыками пользователя и навыками, необходимыми для достижения выбранной карьерной цели.

Например:

| Навык      | Требуемый уровень | Текущий уровень | Gap |
| ---------- | ----------------: | --------------: | --: |
| JavaScript |                 4 |               3 |   1 |
| React      |                 3 |               2 |   1 |
| TypeScript |                 3 |               0 |   3 |
| Git        |                 2 |               2 |   0 |
| REST API   |                 3 |               1 |   2 |

Это позволяет перейти от общего вопроса:

> «Что мне изучать?»

к конкретному:

> «Какие навыки мне сейчас необходимо развивать для достижения выбранной цели?»

## Конкуренты и аналоги

При проектировании были рассмотрены существующие решения:

### Яндекс Карьерный навигатор

Сервис анализирует навыки, необходимые рынку, и предлагает пользователю следующие шаги развития и план по навыкам.

**Сходство:** анализ навыков и формирование карьерного плана.

**Отличие концепции проекта:** наш сервис ориентирован прежде всего на анализ требований конкретного рынка вакансий и построение Skill Gap между требованиями позиции и текущими навыками пользователя.

### hh Карьера

Платформа использует данные hh.ru для анализа профессий, навыков и карьерных траекторий, а также предлагает обучение.

**Сходство:** использование данных рынка труда и карьерных траекторий.

**Отличие концепции проекта:** основной объект нашего проекта — не образовательная платформа, а алгоритм формирования персонального маршрута развития навыков.

### LinkedIn Career Explorer

Сервис LinkedIn сопоставляет навыки и профессиональные роли и показывает возможные карьерные переходы.

**Сходство:** сопоставление навыков и профессиональных позиций.

**Отличие концепции проекта:** наш сервис ориентирован на последовательное устранение Skill Gap для достижения конкретной выбранной позиции.

### O*NET

O*NET предоставляет структурированные сведения о профессиях, навыках, технологиях и требованиях к ним.

**Сходство:** связь профессий и навыков.

**Отличие концепции проекта:** O*NET является базой профессиональной информации, тогда как наш проект предполагает анализ актуальных вакансий и формирование индивидуального маршрута.

## Особенность проекта

Ключевая идея системы:

> **Не просто показать, какие навыки нужны профессии, а определить разрыв между требованиями рынка и текущими навыками конкретного пользователя и превратить этот разрыв в последовательный план развития.**

Таким образом, система объединяет:

```text
Рынок вакансий
      +
Требования профессии
      +
Профиль пользователя
      ↓
   Skill Gap
      ↓
Приоритеты развития
      ↓
Карьерный трек
```

## Предполагаемые сущности системы

На этапе проектирования предполагается работа со следующими основными сущностями:

* **User** — пользователь;

* **Vacancy** — вакансия;
* **Profession** — профессиональная позиция;
* **Skill** — навык;
* **Skill Category** — категория навыка;
* **User Skill** — навык пользователя и его уровень;
* **Skill Requirement** — требование профессии к навыку;
* **Skill Gap** — дефицит навыка;
* **Career Track** — карьерный маршрут;
* **Track Step** — отдельный шаг маршрута;
* **Progress** — прогресс пользователя.
