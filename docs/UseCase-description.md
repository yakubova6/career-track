# Описание Use Case Diagram (высокоуровневая диаграмма прецедентов)

## Стейтхолдеры проекта:

> Стейкхолдер — тот, кому важна система (может не взаимодействовать с ней напрямую)

| Стейкхолдер                       |	Интерес                                     |
| --------------------------------- | ------------------------------------------- |
| Студент / начинающий специалист   |	Получить понятный план развития навыков     |
| Вуз / образовательная организация |	Повысить трудоустройство выпускников        |
| Работодатель                      |	Получать кандидатов с релевантными навыками |
| Администратор системы             |	Качество справочных данных                  |
| Источники вакансий (hh.ru и др.)  | Актуальность данных о рынке труда           |
| Команда проекта	                  | Реализуемость и сопровождаемость системы    |

## Акторы системы:

> Актор — тот, кто взаимодействует с системой напрямую

| Актор                     |	Тип             |	Цель                                            |
| ------------------------- | --------------- | ----------------------------------------------- |
| Студент                   |	Человек         |	Построить карьерный трек и отслеживать прогресс |
| Администратор             |	Человек       	| Управлять справочными данными системы           |
| Внешний источник вакансий |	Внешняя система |	Передавать данные о вакансиях                   |
| Сервис аутентификации	    | Внешняя система |	Подтверждать вход пользователя                  |

## Границы системы:
Входит в систему (In Scope):

    Авторизация и регистрация

    Выбор карьерной цели

    Указание текущих навыков и уровня владения

    Анализ Skill Gap

    Построение карьерного трека

    Визуализация трека

    Отслеживание прогресса

    Управление справочниками (профессии, навыки, категории)

    Контроль данных о вакансиях

    Приём данных от внешнего источника вакансий

Не входит в систему (Out of Scope):

    Образовательная платформа (курсы, лекции)

    Интеграция с календарями

    Система штрафов и мотивации

    Прямой чат с работодателем

    Платежи и подписки

| Use Case                 | Описание                                           |
| ------------------------ | -------------------------------------------------- |
| Авторизоваться           | Вход в систему через внешний сервис аутентификации |
