# US-5: Получение карьерного трека

## Use Story
__Как__ студент  
__я хочу__ получить пошаговый карьерный трек на основе моего Skill Gap,  
__чтобы__ знать, какие навыки развивать и в каком порядке, а не собирать план самостоятельно.

## FR (функциональные требования)
1. __FR1__: Система должна формировать последовательность шагов трека только из навыков, входящих в Skill Gap пользователя;

2. __FR2__: Система должна располагать шаги трека с учётом зависимостей между навыками (зависимый навык идёт после навыка-предусловия);

3. __FR3__: Система должна добавлять в конец трека шаг "Практический проект" и шаг "Подготовка к собеседованию".

## AC (критерии приёмки)

1. __AC-1__ (FR1)  
    __Given__: Skill Gap пользователя содержит "REST API", "TypeScript" и "React"; "Git" освоен и в разрыв не входит  
    __When__: Пользователь нажимает "Построить карьерный трек"  
    __Then__: Трек содержит шаги для "REST API", "TypeScript" и "React", шага для "Git" в треке нет  

2. __AC-2__ (FR2)  
    __Given__: В Skill Gap есть "React" и "JavaScript", при этом "React" зависит от "JavaScript"  
    __When__: Система строит трек  
    __Then__: Шаг "JavaScript" стоит в треке раньше шага "React"  

3. __AC-3__ (FR3)  
    __Given__: Трек успешно сформирован  
    __When__: Пользователь открывает последние шаги трека  
    __Then__: Последними двумя шагами являются "Практический проект" и "Подготовка к собеседованию" в указанном порядке  

## NFR (нефункциональные требования)
1. __NFR1__: Построение карьерного трека занимает не более 5 секунд.

2. __NFR2__: При недоступности внешнего API вакансий система строит трек на последних сохранённых данных и показывает пользователю предупреждение об их актуальности.
