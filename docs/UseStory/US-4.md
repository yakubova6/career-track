# US-4: Просмотр Skill Gap

## Use Story
__Как__ студент  
__я хочу__ увидеть Skill Gap между моими текущими навыками и требованиями выбранной цели,  
__чтобы__ понять, каких навыков мне не хватает и какие нужно подтянуть.

## FR (функциональные требования)
1. __FR1__: Система должна сравнивать текущий уровень каждого навыка пользователя с требуемым уровнем по выбранной карьерной цели;

2. __FR2__: Система должна рассчитывать величину разрыва по навыку как max(0, требуемый уровень - текущий уровень);

3. __FR3__: Система должна разделять навыки на три группы: освоенные (разрыв = 0), требующие улучшения (разрыв > 0 при наличии навыка) и отсутствующие (навык не указан).

## AC (критерии приёмки)

1. __AC-1__ (FR1)  
    __Given__: У пользователя указан навык "JavaScript" с уровнем 3, требуемый уровень для цели "Frontend Junior" - 4  
    __When__: Пользователь открывает экран Skill Gap  
    __Then__: Навык "JavaScript" отображается в группе "Требующие улучшения" с текущим уровнем 3 и требуемым 4  

2. __AC-2__ (FR2)  
    __Given__: Для навыка "TypeScript" требуемый уровень 3, пользователь его не указывал (текущий = 0)  
    __When__: Система рассчитывает Skill Gap  
    __Then__: Величина разрыва по "TypeScript" равна 3  

3. __AC-3__ (FR3)  
    __Given__: По навыку "Git" требуемый уровень 2 и текущий уровень пользователя 2  
    __When__: Пользователь открывает экран Skill Gap  
    __Then__: Навык "Git" отображается в группе "Освоенные", его разрыв равен 0  

## NFR (нефункциональные требования)
1. __NFR1__: Расчёт и отображение Skill Gap занимают не более 2 секунд для цели с 30 навыками.

2. __NFR2__: Экран Skill Gap доступен на мобильных устройствах и десктопе без потери читаемости таблицы.
