# Термины, бизнес-правила и сущности предметной области

## 1. Термины предметной области

В соответствии с анализом предметной области необходимо сформировать единый словарь терминов с однозначными определениями.

| Термин                                      | Определение                                                                                               |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Профессия (Profession)**                  | Профессиональное направление, для которого пользователь формирует карьерную цель.                         |
| **Карьерная цель (Career Goal)**            | Выбранное пользователем профессиональное направление, к которому он стремится.                            |
| **Вакансия (Vacancy)**                      | Предложение работодателя, содержащее требования к кандидату.                                              |
| **Навык (Skill)**                           | Компетенция, необходимая для выполнения профессиональных задач.                                           |
| **Hard Skill**                              | Профессиональный технический навык, необходимый для выбранной профессии.                                  |
| **Soft Skill**                              | Гибкий навык, связанный с коммуникацией, организацией работы и другими личными компетенциями.             |
| **Требование к навыку (Skill Requirement)** | Требуемый для профессии или вакансии навык и соответствующий ему уровень.                                 |
| **Уровень навыка (Skill Level)**            | Степень владения пользователем определённым навыком.                                                      |
| **Skill Gap**                               | Разрыв между текущими навыками пользователя и навыками, необходимыми для выбранной профессиональной цели. |
| **Карьерный трек (Career Track)**           | Последовательный план развития пользователя для достижения выбранной карьерной цели.                      |
| **Шаг карьерного трека (Track Step)**       | Отдельный этап развития навыка в составе карьерного трека.                                                |
| **Прогресс (Progress)**                     | Текущее состояние продвижения пользователя по карьерному треку.                                           |

---

## 2. Бизнес-правила

Бизнес-правила определяют условия и ограничения, действующие в предметной области. В отличие от технических ограничений, они описывают логику самой предметной области.

**БП-1.** Требования к профессии определяются на основе анализа требований, содержащихся в вакансиях.

**БП-2.** Навыки разделяются на две категории: **Hard Skills** и **Soft Skills**.

**БП-3.** Для требуемого навыка учитывается необходимый уровень владения.

**БП-4.** Skill Gap определяется путём сравнения текущих навыков и уровней пользователя с требованиями выбранной профессиональной цели.

**БП-5.** Навыки, которых пользователю не хватает или уровень которых необходимо повысить, становятся направлениями развития.

**БП-6.** На основе выявленного Skill Gap формируется последовательный карьерный трек.

**БП-7.** При формировании карьерного трека учитываются зависимости между навыками: освоение одних навыков может быть необходимо перед освоением других.

**БП-8.** Карьерный трек должен обеспечивать последовательное движение пользователя от его текущего уровня подготовки к выбранной профессиональной цели.

## 3. Сущности предметной области

При анализе предметной области необходимо выделить ключевые объекты и их характеристики. Также для объектов могут рассматриваться их состояния и изменения состояний.

| Сущность              | Назначение                                                                            |
| --------------------- | ------------------------------------------------------------------------------------- |
| **User**              | Пользователь системы, который выбирает карьерную цель и развивает необходимые навыки. |
| **Career Goal**       | Карьерная цель пользователя.                                                          |
| **Profession**        | Профессиональное направление, для которого определяется набор необходимых навыков.    |
| **Vacancy**           | Вакансия, используемая как источник требований рынка труда.                           |
| **Skill**             | Навык, используемый для описания требований и компетенций пользователя.               |
| **Skill Category**    | Категория навыка, например Hard Skill или Soft Skill.                                 |
| **User Skill**        | Информация о навыке пользователя и уровне его владения.                               |
| **Skill Requirement** | Требование к определённому навыку для выбранной профессии или вакансии.               |
| **Skill Gap**         | Разница между текущими навыками пользователя и необходимыми навыками.                 |
| **Career Track**      | Сформированный для пользователя план развития.                                        |
| **Track Step**        | Отдельный шаг в рамках карьерного трека.                                              |
| **Progress**          | Информация о продвижении пользователя по карьерному треку.                            |

---

## 4. Основные связи сущностей

Основные связи предметной области можно представить следующим образом:

```text
Вакансия
   ↓
Требования к навыкам
   ↓
Профессия / карьерная цель
   ↓
Сравнение с навыками пользователя
   ↓
Skill Gap
   ↓
Карьерный трек
   ↓
Шаги карьерного трека
   ↓
Прогресс пользователя
```

Таким образом, предметная область системы связана с развитием пользователя в направлении выбранной профессиональной цели. Система использует данные о вакансиях и необходимых навыках, сопоставляет их с текущими навыками пользователя, определяет Skill Gap и на его основе формирует последовательный карьерный трек.

Описание соответствует принципам анализа предметной области: рассматриваются **процессы, бизнес-правила, терминология и ключевые сущности**, без перехода к реализации интерфейса, базы данных или программного кода.
