## 1. Введение

**Предметная область (Domain)** — реальный мир (бизнес, процессы, правила), для которого создаётся информационная система.

**Анализ предметной области** — изучение этого мира **до** принятия технических решений с целью выявления скрытых правил, ограничений и терминологии.

Для проекта «Интерактивный конструктор карьерного трека» предметная область — это пересечение трёх миров:

1. **Рынок труда** — вакансии, требования работодателей, тренды.
2. **Профессиональные компетенции** — навыки, уровни владения, зависимости.
3. **Профиль пользователя** — текущие навыки, карьерная цель, прогресс.

---

## 2. Выбор сложных прецедентов для моделирования

Согласно лекции, **Activity Diagram обязательна только для сложных процессов**, где есть:
- 3+ ветвления;
- альтернативные потоки;
- смена статусов объектов;
- внешние роли и системы.

Линейные процессы (например, «Создать профиль», «Указать навык») не требуют диаграммы деятельности — достаточно текстового Use Case с Acceptance Criteria.

### Выбранные сложные прецеденты:

| № | Прецедент | Почему сложный |
|---|-----------|----------------|
| **1** | Построение карьерного трека | Многошаговый процесс: анализ вакансий → извлечение навыков → классификация → сравнение с профилем → расчёт Skill Gap → определение приоритетов → учёт зависимостей → генерация последовательности шагов. |
| **2** | Анализ Skill Gap | Сравнение текущего уровня пользователя с требуемым по каждому навыку, ветвления по уровням, учёт категорий Hard/Soft, формирование итогового списка дефицитов. |
| **3** | Анализ вакансий и извлечение требований | Внешний источник данных (API), фильтрация, парсинг, нормализация навыков, классификация, частотный анализ, обработка ошибок. |

- **Пользователь** (студент)
- **Система** (конструктор карьерного трека)
- **Внешний источник вакансий** (API рынка труда)
